# 栗本｜プレイヤーを引っ張って飛ばし、止まったら次の手へ

**目標：壁や敵がまだなくても、球を発射して停止させ、もう一度発射できるようにする。**
担当表：15–17,32–33行（ID4,8）。ブランチ：`feature/player-motion`

## 1. 作るファイル・作る順番

すでに配布されたhを利用し、対応するcppを実装する。ファイル名・関数の型は変更しない。

| 順番 | 場所（Source/Game/ 以下） | 作るもの |
|---|---|---|
| 1 | Components/BallMotionComponent.h/.cpp | 球を動かして止める |
| 2 | Systems/TurnSystem.h/.cpp | 何回発射できるか管理 |
| 3 | Components/PlayerInputComponent.h/.cpp | マウスを引っ張っているか記録 |
| 4 | Components/PlayerLaunchComponent.h/.cpp | 引っ張った距離から発射速度を計算 |

マウスをゲーム内の座標に変換する処理はリードが作る。今回はマウス座標を自分で取得しなくてよい。`GameTypes.h` にある `PointerFrame`（マウス情報）と `AimState`（引っ張り情報）を使う。

## 2. BallMotionComponent（動いて止まる球）

最初にこれを完成させる。小栗さんも速度取得・変更の関数を使う。

| 関数 | 中に書く処理 |
|---|---|
| `Configure(deceleration, stopSpeed, maxSpeed)` | 1秒あたりの減速量、停止とみなす速度、最高速度を設定する。負数や正常でない数値を受け入れない。最高速度は正の値にする |
| `SetVelocity(BoardVec2 v)` | 速度のX/Zを保存する。最高速度を超えたら向きを変えずに長さだけ最高速度にする。NaNや無限大は拒否する |
| `GetVelocity()` | いまの速度を返す |
| `IsMoving()` | 速度の長さが停止速度より大きければtrue |
| `Stop()` | X/Z速度を両方0にする |
| `GetDeceleration/GetStopSpeed/GetMaxSpeed()` | 対応する設定値を返す |
| `Update(float dt)` | 下の4手順を実行する |

**Updateの中身を考える順番**

1. `m_pOwner` が空、dtが負・不正なら処理しない。既に停止速度以下なら速度を0にして終了。
2. `Transform& t = m_pOwner->GetTransform();` で位置を取得する。
3. `t.position[0] += m_velocity.x * dt;`、`t.position[2] += m_velocity.z * dt;` で動かす。Yは変更しない。
4. 速度の長さを `sqrt(x*x + z*z)` で求め、`deceleration * dt` だけ減らす。新しい長さが停止速度以下なら `Stop()`。まだ動くならX/Z両方に「新しい長さ ÷ 元の長さ」を掛ける。0で割らないよう注意。

例：速度(-4,0)を0.5秒、減速量4で更新すると、Xは-2移動し、次の速度は(-2,0)になる。マイナス方向に動く球も正しく止まる。

## 3. TurnSystem（手数と次の発射を管理する）

Componentではない普通のクラスで、SceneGameが呼ぶ。`m_remaining` は残り手数、`m_resolving` は「いま球が動き終わるのを待っているか」。

| 関数 | 中に書く処理 |
|---|---|
| `Reset(int shots)` | 残り手数を初期化（負数は0として扱う）、発射待ち状態にする |
| `CanLaunch()` | 残り手数が1以上、かつm_resolvingがfalseならtrue |
| `TryConsumeShot()` | CanLaunchがfalseなら何もせずfalse。trueなら残り手数を1減らし、m_resolvingをtrueにしてtrueを返す |
| `EndIfStopped(bool anyMoving)` | 発射後で、anyMovingがfalseの時だけm_resolvingをfalseにしてtrueを返す。それ以外はfalse |
| `GetRemainingShots()` | 残り手数を返す |
| `IsResolving()` | m_resolvingを返す |

例：残り2手 → 発射成功で1手 → 動いている間は発射不可 → 全球停止で再び発射可能。残り0でも最後の球が止まるまではm_resolvingがtrue。勝敗そのものはリードが判定する。

## 4. PlayerInputComponent（マウスを引っ張る状態を記録）

`Sample(const PointerFrame& frame, bool canAim)` を1フレームに1回、SceneGameが呼ぶ。`m_aim` に情報を覚えておく。

| 渡される値 | 意味 |
|---|---|
| valid | マウス情報が有効か |
| pressed / held / released | 押した瞬間 / 押し続けている / 離した瞬間 |
| hitPlayer | 押した場所がプレイヤーに当たったか |
| point | ゲーム内のX/Z座標 |
| canAim | 今発射の準備をしてよいか |

**Sampleの手順**

1. 前回の `m_aim.released` をfalseにする。
2. `!frame.valid` または `!canAim` なら `Cancel()` を呼んで終了。
3. `frame.pressed && frame.hitPlayer` なら `dragging=true` にし、`anchor`（押した場所）と `point`（今の場所）をframe.pointにする。
4. ドラッグ中でheldならpointを更新。プレイヤーから外れても引っ張り続けられる。
5. ドラッグ中でreleasedなら最後のpointを記録し、`released=true`、`dragging=false` にする。anchorとpointは発射計算のため残す。次のSampleではreleasedはfalseに戻る。

`GetAim()` はm_aimを返す。`Cancel()` はドラッグや離した状態を初期化する。ここでは速度も手数も変更しない。

## 5. PlayerLaunchComponent（発射の方向と強さを計算）

`TryBuildVelocity(const AimState& aim, BoardVec2& out) const` を実装する。成功したらoutに速度を入れてtrueを返す。発射できない場合はfalseを返す。

1. `aim.released` がfalseなら失敗。
2. 方向を `anchor - point` で求める（引っ張った方向と逆に飛ぶ）。X同士、Z同士を引き算する。
3. その長さを `sqrt(x*x+z*z)` で求める。最小ドラッグ距離より小さければ失敗。長さ0も失敗。
4. XとZを元の長さで割り、長さ1の方向にする。
5. `距離 / 最大ドラッグ距離` を0〜1に制限し、最大速度を掛ける。
6. 方向のX/Zに求めた速度の長さを掛けてoutに入れ、trueを返す。

`Configure(minDrag,maxDrag,maxSpeed)` は値を設定する。距離や速度が不正でないか確認（maxDrag>0、0≤minDrag≤maxDrag、maxSpeed>0）。3つのGetterは各値を返す。仮値はmin=0.1、max=3、速度10。

例：押した位置(0,0)、離した位置(-3,0) → 右向きの速度(10,0)。距離を6まで引っ張っても速度10を超えない。ここでは球の位置も手数も変えない。実際に発射するのはSceneGame。

## 6. 共通の仕上げ（3つのComponent）

- コンストラクタでは `: Component(pOwner)` とする。Cloneでは `pNewOwner` を使い、有効/無効と設定値をコピーする。
- BallMotionの保存/Clone対象は減速・停止速度・最高速度。速度は0へ戻す。PlayerLaunchは最小/最大ドラッグと最高速度。PlayerInputは設定なし（ドラッグ状態は初期化）。TurnSystemはComponentではないので登録・保存不要。Resetで初期化する。
- Inspectorを `_DEBUG` の中で作る。登録コード（create/save/load）はリードに渡す。
- SampleやTryBuildVelocityはSceneGameが呼ぶ。Update内からもう一度呼ばない。

使ってよい関数：`m_pOwner` / `GetOwner()`、`GetTransform()`、`GetComponent<T>()`、`IsEnabled()/SetEnabled()`、`Clone()`。GameObject.hは必要なcppでincludeする。

## 7. 完成チェック（上から試す）

| テスト | 正解 |
|---|---|
| SphereにBallMotionを付け、速度(2,0)、減速0でUpdate(0.5) | Xが+1、Y不変 |
| 減速4で正・負方向へ移動 | どちらも徐々に停止 |
| Reset(2) → TryConsumeShotを2回 | 1回目trueで残り1、2回目false |
| EndIfStopped(true) → false引数 → もう一度false引数 | 戻り値false → true → false |
| 残り1で最後の発射 | 残り0、全球停止までIsResolving=true |
| (0,0)から(-3,0)で離す | 仮設定で速度(10,0) |
| 逆方向、最小距離未満、canAim=false、valid=false | 方向が逆になる／発射しない／ドラッグを中止 |

テストは別ステージや自分のローカル検証コードで行う。MoveComponentは同時に付けない。SceneGameへの接続はリードへ依頼。

**変更しないもの：** CollisionSystem、Health、HUDの内部、SceneGame等の共通ファイル、他人のステージ。共通ルール00も確認。

## 補足用語

| 用語 | 意味 |
|---|---|
| 速度ベクトル | どっちにどのくらい速く動くかをX/Zで示す値 |
| 単位ベクトル | 長さが1の方向。方向を残したまま速度だけ変えられる |
| clamp（値の制限） | 例：0未満は0、1超えは1にする。C++14ではif文などで書けばよい |
| dt | 今回の更新で進める秒数 |
| 引数の `&` | 呼び出した側の変数を使う。outに結果を入れて返せる |
| Resolving | 発射後、すべての球が止まるのを待っている状態 |
| NaN/Inf | 正常でない数値。`std::isfinite` で検査できる |
